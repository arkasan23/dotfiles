# Dot files repo on Arch Linux w/hyprland 
Arch Linux install using archisntall with hyprland DE selected. 

## Using this preconfigured hyprland setup
https://github.com/end-4/dots-hyprland

### Dependencies
Git, Stow, Lazyvim

For tmux, make sure the tmux plugin manager is installed via git

For stow: go into dotfiles fodler and run the command: stow --adpot .
